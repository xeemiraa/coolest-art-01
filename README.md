# Make the coolest art — Entry for make.fun bounty

Generative art program that creates "Eternal Bloom" — a vibrant,
abstract composition with concentric rings, galactic spiral arms,
star field, and central glow.

## Output

- **Image**: 1024×1024 PNG, RGBA, ~0.58 MB
- **Location**: `/output/entry.png`
- **Deterministic**: same output every run (seeded PRNG)

## Run

```bash
node main.js
